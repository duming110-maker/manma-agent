## E1 上游 workspace 包存在且持久化

- 包：`packages/workspace/workspace/`（npm 名 `@deepseek-ai/dsh-workspace`）
- README：「Workspace entity registry (`ctx.workspaceRegistry`) … durable workspace records, stable workspace order, and a newest-first candidate session index stored through the domain data form」
- 能力清单（README「Shape」节）：
  - `create(path, title?)`：canonical realpath、拒绝不存在路径、**每路径至多一条记录**（幂等 adopt-or-return）、新记录插入持久顺序头部
  - `get/list/resolveByPath`、`insertBefore`（持久显示顺序）、`delete`（只删注册，**目录/文件/会话日志不动**，会话变为 Ungrouped）
  - `Workspace.attachSession(id)`：**校验会话 header cwd 与工作区路径一致**后计入分组
  - `archiveSession(id)` / `archivedSessionIds`：注册表全局归档集，「an archived session disappears from grouping surfaces but keeps its session log and its `sessionIds` slot, so a future unarchive restores its position」
  - 启动 bootstrap：用 `SessionPersistence.list()` 的 header `id/cwd/createdAt` 自动归组历史会话（不读事件体）
- 设计决策记录：「Session deletion and destructive folder removal are separate, absent capabilities」——上游有意只提供归档

## E6 system-prompt 注入接缝（section / context / waterfall）

- 包：`packages/core/system-prompt/`（npm 名 `@deepseek-ai/dsh-system-prompt`，web-app bundle L111 挂载）
- README 要点：
  - `ctx.systemPrompt.section(section)`：静态段，有序（order band：-100 身份 / 0 persona / 100-199 工具指引），scope 分层（agent ctx 可 shadow 全局同名段）
  - `ctx.systemPrompt.context(context)`：「Contribute ordered dynamic context … Providers are evaluated for each eligible assembly and **become a sourced runtime-context snapshot in model history** under the shipped loop」——**注入内容天然落模型历史，满足 C6**
  - `ctx.systemPrompt.variable(name, provider)`：`{{name}}` 模板变量（loop 已注册 `model`/`cwd`）
  - `system-prompt/assemble` waterfall：每次组装可协作改写
  - KV Cache effect 节：「Any change may invalidate reuse from the first changed system-prompt token」——可变内容放 section 会使前缀缓存失效；context 为 user-role 快照不受影响
  - `AssembleContext` 支持 declaration merging，`dsh-agent` 已声明 `agent` 字段——按会话/工作区过滤注入内容可行
- 推论（评审 P1-1）：krm 三段应走 `context()`，方案 §6 的「手写 session 事件落日志」改为依赖上游快照。
