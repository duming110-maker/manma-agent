# 2026-08-18 · P2-a：bc-web-ui 真实外壳骨架（用户可见价值第一卡）

## 决策

**视觉骨架落地**：占位侧栏替换为 frontend-user 形态骨架——三列 grid `300px/1fr/0px`（300px 是 frontend-user 实宽，弃任务卡草写的 260px）、侧栏五分区（品牌区/新建任务/技能·定时任务·设置禁用态/会话空态/用户区+主题切换）、`--bc-*` 令牌体系（frontend-user globals.css 亮暗两表**逐值移植**，评审全表核对零偏差；改名映射 `--bg-nav→--bc-bg-sidebar` 等为一致双射）、`data-bc-theme` 帧内驱动 + `bc-agent-theme` localStorage 持久化。官方对话区结构性零扰动（选择器全部 `.bc-web-ui-*` 作用域，暗表挂帧不挂 body，官方 ThemePresenter 零改动）——**官方/自研两套主题并存是本阶段的既定行为**，换肤桥接后续卡。

**产物契约增量基线**：require 面从 `{react/jsx-runtime}` 增至 `{react, react/jsx-runtime}`（useState 值导入；react 是官方种子冻结表第 1 词）——后续 B5 断言按此基线对账。无新依赖、无 Tailwind（令牌+骨架用原生 CSS）。

**路由定论（评审确认）**：frontend-user 的 BrowserRouter 语义**不可移植**（React Router v7 会违禁新依赖且与宿主 SPA 的 URL 空间冲突）；P2-e 走壳内状态 + 官方 sessions 选择驱动导航，URL 是否映射路径届时定。

## PM 裁决（评审建议采纳）

1. **P2-f 品牌接入点（硬性）**：`--bc-color-primary`（至少 brand-mark + COPY 文案）必须改为从 `branding/` 取源；当前 `rgb(37,99,235)` 按 frontend-user 语义属普通 accent 移植，不违规，但 P2-f 落地前不得进用户可见里程碑。
2. 暗色滚动条值（`rgba(255,255,255,.16/.24)`）是**派生值**非移植值（demo 黑 thumb 在暗底不可见），P2-f 令牌文档标注。
3. COPY 11 条暂 zh-only，P2-f 落 ctx.locale 双语（铁律 4 延后已在卡面授权）。
4. **P2-b 冒烟新增断言**：bc 暗色 × 官方亮色共存时官方输入区文字色不变（继承通道观察项——frame 的可继承属性理论上不外溢，但官方子树若依赖未显式 color 的元素可能错色）。
5. 前瞻性移植未消费令牌（shadow/语义色/mono 字体）保留，P2-b+ 消费。
