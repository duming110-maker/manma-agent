# 2026-08-18 · P0-2：最小布局插件（D1/D2/D10 实证）

## 决策

**root 占位方式**：禁用官方 `ui-layout` 行（overlay `disabled: true`，官方叠层惯用法）后，`@bc-agent/web-ui` 成为内建 `root` slot 的**唯一**注册者（上游 slots.ts 对 root 的 "DO NOT register here" 警告只针对 ui-layout 在场时的遮蔽），以与官方一字不差的 keys/kinds/scopes 重声明 `sidebar/conversation/details/shell.overlay` 四子 seat——官方 conversation 全家（含 ui-workspace/ui-model-selection/ui-tool 等 20+ 个 `slots.inject` 挂载者）原样落位，D2 成立。

**禁用 ui-layout 的两个隐性前置（架构文档此前未写明，已补进 spike 清单）**：
1. `layout` 服务必须有人提供——shell 的 app-shell entry 与 ui-conversation/ui-sidebar 都 inject `layout`，无人提供则 boot sweep fail-loud 整页停在 loading。bc-web-ui 以 no-op 面接管（`toggleSidebar/openDetails` 无效，详情列暂不可开，P1/P2 接真 store）。
2. ThemePresenter 必须重新就位（colorScheme + `data-ds-dark-theme` + alias-token 内联 + theme-color meta），否则官方组件调色板全灭。bc 按同契约极简实现，无残差。

**侧栏策略**：单 seat 第二注册是**遮蔽**不是叠加（SlotCore 语义），故自研侧栏是框架自有 markup；`sidebar` seat 保持声明（ui-sidebar 注册合法）但**不渲染**（死挂载、无副作用）。

**组装与启动**：`profiles/bc-agent/cordis.patch.yml`（disable ui-layout + insert bc-web-ui 行）由 `apps/desktop` 经 `dsh web --patch` 叠加；插件安装走官方 `dsh plugin --profile web add link:<repo>/packages/web-ui`（一次性 live link，改码后 rebuild+重启即生效）。构建形态：Node 半普通 ESM + 浏览器半 `window.__ModuleLoader__` 注册壳（esbuild 双产物），`dsh.client {platform:'web', inject:[runtime,ui-theme]}` manifest；包必须可从 profile 目录 resolve（`exports['./package.json']` 是扫描器硬性要求——skin-plugin 踩坑记录）。

**D10 实证**：`lib/client.js` 唯一外部 require 是 `react/jsx-runtime`（官方 shell 种子模块表冻结词），peer `react ^18.2.0` 与上游全线一致，双 React 实例不可能出现。
