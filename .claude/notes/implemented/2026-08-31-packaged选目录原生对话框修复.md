# 2026-08-31 · packaged 选目录原生对话框修复（真 Node 随包分发）

## 是什么

packaged 版（Electron + NSIS）选工作区报 `directory picker failed: win32 folder dialog worker exited before reporting a result`，应用卡死在"必须选工作区"门槛。最终方案：**随包分发真实 node.exe + clear-env 重定向 execPath**，原生对话框端到端验证通过（选定 → 路径回传 → 干净退出）。

## 排查链（三层问题，逐层揭开）

1. **worker 退化成 GUI 实例**：上游 `dsh-host-directory-picker-native` 以 `spawn(process.execPath, [worker.cjs], {env: {...process.env}, stdio ipc})` 自起 worker；bc 的 clear-env.mjs 此前删除 `ELECTRON_RUN_AS_NODE` → worker 变成第二个 Electron GUI 实例（撞单实例锁静默退出）。修复：clear-env 不再删该变量（真 node 忽略它，泄漏到会话 shell 无实际影响）。
2. **koffi 在 Electron 运行时崩溃**：env 修好后 worker 已能弹原生对话框，但取结果路径时 `readUtf16 → koffi.view` **native crash**（desktop.log：`FATAL ERROR: Error::New napi_get_last_error_info`）。koffi 在 Electron-as-node（abi 148）下加载成功但 napi 错误路径崩——深水区不可控。
3. **最终修复——让 worker 跑在真实 Node 上**：dist 把构建机 node.exe 拷入产物（`extraResources` → `<根>/resources/runtime/node.exe`，物理、app.asar 外）；clear-env（bc 在 dsh 进程内的合法注入点）把 `process.execPath` **defineProperty 强制重写**指向它（普通赋值静默失败——该属性 writable: false 但 configurable: true）。上游全部"execPath 自 spawn"随之落在真实 Node 上。

## 放弃/偏差

- **browse 后端钉死是中间方案，已回退**：profile patch disable auto + insert browse 对曾端到端跑通，但目标用户是普通办公人员，目录树浏览 + 手输路径不可接受，原生对话框必须保留。
- 放弃修 koffi/Electron 兼容：上游依赖深水区，bc 不可控。
- 放弃 clear-env 删除纪律（参考项目 desktop-runtime-environment.ts 原设计）：它破坏上游"execPath 可当 node 自 spawn"假设，packaged 形态下必须保留该变量。

## 验证

- 分层复刻逐环排除：worker.cjs 单跑 ✓、koffi 加载 ✓、Electron-as-node spawn ✓、env 传递 ✓、真 node spawn worker + 键盘自动化完成真实选定 → `{"kind":"done","path":"E:\aiproject\bc-agent-desktop"}` + `WORKER_EXIT 0` ✓（崩溃点消失）。
- dsh 进程视角：`--import clear-env` 后 `process.execPath` = 随包 node.exe ✓。
- 含空格安装路径（`E:\aiproject\bc space test\`）全流程：三插件安装 ✓、服务起 ✓、原生对话框 ✓。
- 实机 GUI 人工验证（选目录 → 建会话）待用户确认；自动化已覆盖到 worker 回传层。

## 踩坑记录

- 上游 `dsh plugin add`（pnpm 转发 `shell: true` 裸拼参数）遇含空格安装路径必挂——tarball 先物理拷无空格 staging 再装（`launcher.bcPluginSpecs` stagingDir，同日另一提交）。
- UI 报错（exit 无消息）极具误导性：worker 崩溃真因藏在 dsh 的 stderr pipe（`%APPDATA%/<brandId>/logs/desktop.log`）的 native stack 里。
- `process.execPath` 在 Electron 里是 writable: false 数据属性，普通赋值静默失败，须 `Object.defineProperty`。
- resources/ 经 files+asarUnpack 会进 `app.asar.unpacked/resources/`（深一层）；要落在 app.asar 同级须用 `extraResources`（并在 files 排除防重复）。
- worker 崩溃栈要靠 100ms 轮询 `Win32_Process` 抓闪现进程 + desktop.log 定位；`process.execPath` 重定向生效与否用 `--import clear-env -e "console.log(process.execPath)"` 直接验证。
