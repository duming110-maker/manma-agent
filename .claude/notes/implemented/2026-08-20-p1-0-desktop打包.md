# 2026-08-20 P1-0 桌面壳打包（Electron 精简壳 + NSIS 安装包）

## 是什么

P1-0 核心可安装包（用户决策：托盘简单版；自动更新/PS7 检测/last-known-good 回滚后置 P5）。架构：保留 spawn dsh 子进程套 Electron 壳（非参考项目的进程内 boot）。产出 `apps/desktop/dist/BC-Agent-<ver>-x64-Setup.exe`。

1. **Electron 壳**（`apps/desktop/electron/`）：
   - `main.js`：单实例锁、per-brand userData/DSH_HOME、`writeRuntimeShims`（clear-env + node.cmd + pnpm.cmd）、`launcher` 编排、fail-loud 原生对话框（附 dsh 日志尾部）；
   - `window.js`：contextIsolation + sandbox + 无 preload、同源导航校验、外链走系统浏览器、close 隐藏（托盘常驻）；
   - `tray.js`：简单托盘（打开主窗口/退出）。
2. **共享编排**（`apps/desktop/src/launcher.mjs`）：`resolveDshBin`、`ensurePluginsReady`（dev link / packaged tarball）、`spawnDshWeb`（RunAsNode trampoline + 端口解析）。dev 纯 node（`src/main.mjs`，runAsNode:false）与 Electron（runAsNode:true）共用。
3. **打包脚本**（`scripts/`）：`dist.mjs`（品牌→图标→tarball→electron-builder→verify）、`pack-plugins.mjs`（`pnpm pack` bc 插件到 resources/plugins/）、`generate-icons.mjs`（手写 PNG 编码 + png-to-ico，免 sharp）、`after-pack.mjs`（unpacked 断言）、`verify-installer.mjs`（PE 头 + 产物断言）。
4. **前置**：node-pty pnpm patch（`patches/node-pty@1.2.0-beta.15.patch`，上游拷贝，`DSH_NODE_PTY_SPAWN_HELPER`）；`branding.yaml` 加 `desktop:` section（brandId/appId/productName/executableName/icon/trayIcon/updateUrl/uninstallerDeleteAppData）；web-ui build.mjs sourcemap（C9 由 404→200）+ `BC_BRAND_DIR` 品牌化。

## 验证（packaged 冒烟）

- **dist**：`pnpm run dist` → `dist/BC-Agent-0.1.0-x64-Setup.exe` 生成；afterPack 断言 PASS（tarball/cordis.patch/branding/node-pty prebuilds/koffi native）；verify-installer PASS（PE 头 + 产物）。
- **dev:electron**：Electron 壳 + per-brand DSH_HOME（%APPDATA%/bc-agent）+ pnpm shim + 插件 link + spawn dsh + 页面全链路通。
- **packaged 首启**（win-unpacked/BC Agent.exe，等价安装后运行）：全新 %APPDATA%/bc-agent 自举 → tarball 插件安装（profile 里 @bc-agent/web-ui + capability-core）→ dsh web 起来（端口随机）→ 页面 200 含 __DSH_BOOT__ → `/plugins/@bc-agent/web-ui/client.js.map` **200**（C9 sourcemap 生效）→ 窗口标题 DeepSeek Harness。**安装即用核心验收通过**。

## 踩坑记录

- **electron-builder JS 配置里 `${arch}`/`${ext}` 是宏**：不能作为 JS 模板变量求值（ReferenceError），用字符串字面量 `'${arch}'` 保留给 electron-builder 替换。
- **afterPack 的 appOutDir**：= win-unpacked 根；`app.asar.unpacked` 在其 `resources/` 子目录（非 appOutDir 直接下）。
- **`process.resourcesPath` 已是 win-unpacked/resources**：不能再过 `app.asar→app.asar.unpacked` 字符串替换（会变 `unpacked.unpacked`）。
- **pnpm pack tarball 名**：`@bc-agent/web-ui` → `bc-agent-web-ui-<ver>.tgz`（`/`→`-`）；匹配用 `scopeName.replace('@','').replace('/','-')`。
- **electron-builder 用 npm collector**：pnpm 隔离布局产生大量 `duplicate dependency references` 警告（正常，仍能复制）；依赖复制约 7 分钟（dsh 全家 100+ 包）。
- **electron 二进制下载**：GitHub 直连超时，需 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`（本机已缓存到 pnpm store）。
- **electron-builder 不在 PATH**：`spawnSync('electron-builder')` 失败，改 `process.execPath <node_modules/electron-builder/cli.js>`。
- **pnpm 包不导出 `./package.json`**：`require.resolve('pnpm')` 从主入口反推包目录。
- **dev 纯 node 与 Electron 分支**：`launcher` 加 `runAsNode` 开关（Electron 加 `--expose-internals --import clear-env`，纯 node 不加）；`buildChildEnv` 只供 Electron（设 ELECTRON_RUN_AS_NODE）。
- **electron-builder × pnpm 是最大的坑**：npm collector 对 pnpm 隔离布局系统性漏收集（虚拟根 @scope 包 @img/colour、platform 预编译包 @koromix/@img/sharp/@vscode、optional/peer 引用的 dsh 成员 dsh-session-stats 等）→ packaged 启动 fail-loud（Cannot find package / native module）。解法：
  1. **触发 pnpm collector**：dist env 设 `npm_config_user_agent: pnpm/...` → electron-builder 环境检测命中 pnpm（保留 .pnpm 多版本嵌套，避免扁平化版本冲突如 schemastery `looseObject`）；
  2. **显式加漏收集包**到 apps/desktop dependencies（dsh 闭包 20 个 + @koromix/koffi-win32-x64 + @img/sharp-win32-x64 + @vscode/ripgrep + dsh-session-stats + dsh-client-ui-input-trigger）；
  3. **afterPack 复制兜底**：platform 原生包 + 顶层 @deepseek-ai 显式 deps（dereference 真实文件）进 app.asar.unpacked；
  4. `electronVersion` 显式钉 43.4.0（staging/收集时 electron 是 devDep 不在闭包）。
- **依赖收集/版本**：pnpm 虚拟根 `.pnpm/node_modules`（hoist 的 @scope 包）npm collector 不识别；platform native 在独立包（@koromix/koffi-win32-x64 的 win32_x64/koffi.node、@img/sharp-win32-x64 的 lib/*.node）；扁平物化（手动物化脚本）会导致 schemastery/zod 多版本冲突（looseObject）——改用 pnpm collector 保留嵌套。
- **NSIS 安装 UAC**：本机 UAC 弹窗无法静默自动化；安装器 `/S` 卡 elevation。
