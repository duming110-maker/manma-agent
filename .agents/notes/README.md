# Agent Notes — BC Agent Desktop

非平凡决策的留痕机制（镜像上游 deepseek-harness 的 Agent Notes 机制）。

## 何时写

- 一个非平凡的实现/设计决策：为什么、放弃了什么、怎么验证。
- 只有机械/局部改动可豁免。

## 布局

- `implemented/`：已落地的决策（现在时描述"是什么"）。
- `archived/`：被取代的历史（冻结，不作为当前权威）。

## 规则

- 每条一个文件，标题 = 日期 + 主题。
- 落地的 note 描述"是什么"，不用 "should/计划/将" 语气。
- 归档的 note 永不修改。
