# 2026-08-19 · 设置并入官方（规则与记忆 section + 删除自建弹窗 + 主题单一来源）

## 决策

**「规则与记忆」并入官方设置**：注册进官方设置外壳的 `settings.section` 槽（`kind:'list'`，与 Models/Plugins 同一扩展点），`id: 'rules-memory'`、`order: 30`（在 general=0 / models=10 / plugins=15 / agent-presets=20 之后）。内容当前为两张空态卡（规则 / 记忆），capability-krm（P3a）落地后再填 UI。

**槽类型本地声明（不新增 npm 依赖）**：`settings.section` 的 SlotMap 类型由 `@deepseek-ai/dsh-client-ui-settings` 声明，但该包不在 bc 依赖图里。bc 沿用既有模式（对 `sidebar`/`sidebar.settings` 等官方槽的 re-declare），在 `client/index.ts` 的 SlotMap 里本地声明 `'settings.section': { kind:'list'; scope:'root'; owner: BcSettingsSectionOwnerProps{ close } }`，与官方 `SettingsSectionOwnerProps` 结构一致。运行时声明仍由 ui-settings-general 的 SettingsRoot（children）承担，`ctx.slots.inject('settings.section', …)` 等待它出现后注册。**否决先加 `@deepseek-ai/dsh-client-ui-settings` 依赖**：`pnpm install` 会触发 koffi/node-pty 原生构建（spawn）被沙箱拦、且全量重链极慢，收益（一次 type-only import）不成比例。

**删除自建设置弹窗**：删除 `BcSettingsPage.tsx`（规则/记忆/DSH 三栏 + 语言/主题脚栏），侧栏底 `data-bc-user` 直接渲染官方触发器 `renderSlot('sidebar.settings', { wide: true })`（SettingsRoot 自带 trigger + 全屏 panel）。相应清理死 CSS（`bc-web-ui-settings-*` 全套、`bc-web-ui-settings-button`、`bc-web-ui-settings-dsh*`）。

**主题单一来源**：删 bc 自有的 `THEME_STORAGE_KEY`/localStorage/`data-bc-theme` 状态与 `toggleTheme` 双写；`--bc-*` 深色 token 表选择器从 `.bc-web-ui-frame[data-bc-theme='dark']` 改为 `body[data-ds-dark-theme] .bc-web-ui-frame`，跟随 BcThemePresenter 已维护的官方暗色属性。语言/主题改由官方 General 节的 **Language（ui-locale）/ Appearance（ui-theme）** 两行驱动（本就在官方设置里），对 bc 生效：语言走 locale revision（`t` 座位 + `useLocale`），主题走 `theme/change` → presenter 同时上 `--dsw-*` 与 `body[data-ds-dark-theme]`。
